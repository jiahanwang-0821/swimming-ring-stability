# Swimming Ring Stability

This project investigates the hydrostatic and dynamic stability of floating toroidal bodies through mathematical modeling, buoyancy analysis, and numerical simulation.

The project originated from my IB Mathematics AA HL Internal Assessment and was later extended into an undergraduate applied mathematics research project.

## Research Question

How do geometry and mass distribution of an idealized floating torus affect its hydrostatic restoring behavior and nonlinear rotational response?

## Project Components

* Geometry-based torus model
* Hydrostatic stability analysis
* Center of buoyancy calculation
* Nonlinear dynamic stability model
* MATLAB numerical simulation
* Interactive hydrostatic simulators
* Undergraduate thesis report

## Possible Future Extensions

* Wave excitation
* Viscous damping
* Experimental validation
* Non-uniform shell thickness and mass distributions
