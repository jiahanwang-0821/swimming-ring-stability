# MATLAB Code

This folder contains MATLAB scripts used for geometric modeling, visualization, and stability analysis.

Current files:
* swimming_ring_stability_figure1.m
* interactive_swimming_ring_stability_simulator.m
To improve readability, the simulator highlights the stability state using color: green indicates a restoring (stable) configuration, yellow indicates a near-neutral configuration, and red indicates an overturning (unstable) configuration. This color coding is purely a visualization aid and does not affect the underlying hydrostatic calculations.
